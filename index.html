Create an Incident Escalation plugin, add a Skill and remote MCP connector, provision it to Microsoft 365, package it, and test it in Cowork.

1

Open PowerShell as Administrator

  1. Select Start.
  2. Type PowerShell.
  3. Right-click PowerShell 7.
  4. Select Run as administrator.
  5. Select Yes when User Account Control appears.
Important: Use the Administrator window for prerequisite installation. Continue using the same PowerShell window for this lab.
2

Check prerequisites

Check PowerShell version

$PSVersionTable.PSVersion

The major version must be 7 or later.

If PowerShell 7 is missing, run:

winget install --id Microsoft.PowerShell --source winget

Close the window. Then repeat Step 1 and reopen PowerShell 7 as Administrator.

Check Node.js

node --version

Check npm

npm --version

If Node.js or npm is missing, run:

winget install OpenJS.NodeJS

Close and reopen PowerShell as Administrator. Run the Node.js and npm checks again.

3

Install Work IQ Dev Tools

Check WIQD

wiqd --version

If WIQD is not installed, run:

iex "& { $(irm 'https://aka.ms/wiqd/install.ps1') }"

Close and reopen PowerShell as Administrator if the command is not immediately recognized.

Verify WIQD

wiqd --version

Run prerequisite checks

wiqd doctor
Checkpoint: Continue after the required checks pass.
4

Sign in to Microsoft 365

wiqd auth login --interactive

When the directory selection menu appears, select:

Discover my sign-in directory

Complete sign-in with the Microsoft 365 account that you use for Cowork.

5

Create the plugin

Create the lab folder

New-Item -ItemType Directory -Path C:\CoworkLab2 -Force

Open the lab folder

Set-Location C:\CoworkLab2

Create the plugin

wiqd plugin create --name incident-escalation-plugin

Open the plugin project

Set-Location .\incident-escalation-plugin

Confirm the files

Get-ChildItem
6

Add the Incident Escalation Skill

Add the Skill

wiqd plugin add skill --name "Incident Escalation"

Find SKILL.md

$skillFile = (Get-ChildItem -Path . -Filter SKILL.md -Recurse | Select-Object -First 1).FullName

Display the path

$skillFile

Add the Skill instructions

@'
---
name: incident-escalation
description: Investigate critical incidents, identify supported relationships, and prepare a coordinated response recommendation.
---

# Incident Escalation

Use this skill when the user asks to investigate, compare, summarize, or coordinate critical support incidents.

## Workflow
1. Retrieve the relevant incident information using available incident-management tools.
2. Review incident number, priority, state, description, symptoms, affected service, and recent notes.
3. Group incidents only when available evidence supports a relationship.
4. Keep uncertain or unrelated incidents separate.
5. Identify known resolutions or recommended next actions when evidence is available.
6. Prepare a coordinated-work note with a summary, related incidents, evidence, recommended next action, and open questions.
7. Do not modify an incident unless the user explicitly requests and confirms the change.
8. Do not invent incident details. State when required information is unavailable.
'@ | Set-Content -Path $skillFile -Encoding utf8

Review the Skill

Get-Content $skillFile
7

Add the MCP connector

Your instructor will provide your group's Dev Tunnel base URL. The MCP endpoint must end with /mcp.

Set the MCP endpoint

$env:LAB_MCP_URL = "<YOUR-GROUP-DEV-TUNNEL-URL>/mcp"

Example format:

$env:LAB_MCP_URL = "https://example-8000.region.devtunnels.ms/mcp"

Verify the endpoint

$env:LAB_MCP_URL
Checkpoint: The displayed URL must end with /mcp.

Add the connector

wiqd plugin add connector `
  --name "Incident Management" `
  --description "Retrieve incident information and support incident escalation workflows" `
  --url $env:LAB_MCP_URL
8

Provision the local environment

wiqd plugin provision --env local
Why --env local? Provisioning creates and stores the Microsoft 365 app identity, including the app ID required for packaging. Use the same environment for the remaining lifecycle commands. In this lab, that environment is local.
Checkpoint: Continue only after provisioning completes successfully.
9

Package and validate

Create the package

wiqd plugin package --env local

Locate the ZIP

Get-ChildItem -Path . -Filter *.zip -Recurse

Deep-validate the packaged plugin

wiqd plugin validate --mode deep --env local
Order matters: Deep validation requires the ZIP created by the package command.
10

Share and test in Cowork

Set your Microsoft 365 email

$labUserEmail = "<YOUR-MICROSOFT-365-EMAIL>"

Share the plugin

wiqd plugin share --scope users --email $labUserEmail --env local

Open the plugin

  1. Open Microsoft 365 Copilot.
  2. Open Cowork.
  3. Open Sources & Skills.
  4. Select Plugins.
  5. Open Shared with me.
  6. Select the Incident Escalation plugin.
  7. Start a new Cowork task with the plugin enabled.

Run the prompt

Investigate the critical incident queue. Identify incidents that appear to share an underlying issue, keep uncertain cases separate, and recommend the appropriate next action. Do not make any changes without my approval.
